# Digital-Forensics-Report

This repository contains my digital forensics analysis report, where I investigated various files to extract meaningful evidence using standard forensic tools. The process began by navigating into the target directory and reviewing its contents, which led to examining a ransom note PDF. Using pdfinfo, I extracted key metadata and identified the document’s author.

Next, I analyzed an image file using exiftool to uncover hidden metadata, including GPS coordinates embedded within the photo. After retrieving the coordinates, I plotted them on Google Maps to determine the exact physical location associated with the image. This allowed me to identify the street name, Milk Street.

The steps in this report demonstrate practical skills in directory analysis, metadata extraction, geolocation analysis and evidence interpretation, reflecting foundational digital forensics techniques.
